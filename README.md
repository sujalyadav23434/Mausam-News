# Mausaam - Weather & News App

Mausaam is a responsive weather application built using **HTML, CSS, and JavaScript**.

The application allows users to check weather information such as temperature and current weather conditions, while also providing the latest news in a simple and user-friendly interface.

---

Project Overview

The Mausaam app was created to provide users with useful weather information in an easy-to-understand format.

Along with weather details, the application also includes a latest news section, making it possible for users to check weather and stay updated with current news from one place.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling, layout, animations, and responsive design
- **JavaScript** – API integration, dynamic content, and user interactions

---

Features

- 🌡️ Displays current temperature
- 🌤️ Displays current weather conditions
- 📍 Weather information based on location/search
- 📰 Latest news section
- 🔄 Dynamic weather data
- 📱 Fully responsive design
- 💻 Desktop and mobile compatible
- 🎨 Clean and modern user interface
- ⚡ JavaScript-based dynamic content

---

API Integration

The application uses APIs to retrieve dynamic information.

### Weather API

The weather API is used to fetch information such as:

- Temperature
- Weather condition
- Location
- Additional weather details

### News API

A news API is used to retrieve and display the latest news articles.

> API keys should be stored securely and should not be publicly exposed in a GitHub repository.
